CHUMBAK ART - FRONTEND STARTER

HOW TO RUN
1. Extract the ZIP file.
2. Open the chumbak_art_frontend folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Browse Shop, Product Details, Cart, DIY Ideas, Admin and Customer pages.

IMPORTANT
- This is the FRONTEND DEMO. PHP + MySQL backend is not connected yet.
- Demo cart/products use browser localStorage. They are not shared between devices.
- Admin demo login currently opens the dashboard without real authentication.
- To set the client's WhatsApp number, open assets/js/app.js and replace:
  const WHATSAPP_NUMBER = "91XXXXXXXXXX";
  with the client's number including country code, digits only, e.g. "919876543210".
- Product photos currently use illustrative emoji placeholders. Admin can add an image URL in the demo.
- Later we will connect PHP, MySQL Server and MySQL Workbench, secure admin/customer login, persistent products, and order records.
